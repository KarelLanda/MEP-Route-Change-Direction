# Otočit směr TZB trasy (OtocSmerTZB)

Doplněk pro Graphisoft Archicad (29 a 30), který otočí směr vybraných TZB tras (Potrubí, Vzduchotechnika, Kabelové žlaby) při 100% zachování jejich 3D geometrie, kotevních bodů, excentrických přechodů, odboček (TakeOff) a napojených T-kusů (Branch).

## Umístění v menu
- **Hotline Cegra -> Otočit směr TZB trasy**

## Instalace
- **Windows:** Nakopírujte příslušný `.apx` soubor (pro AC29 nebo AC30) ze sekce [Releases](https://github.com/KarelLanda/MEP-Route-Change-Direction/releases) do složky doplňků Archicadu nebo jej načtěte přes Správce doplňků.
- **macOS:** Stáhněte a načtěte `OtocSmerTZB.bundle`.
